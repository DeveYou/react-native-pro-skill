## Shared React Native Pro engineering contract

**Use the local skill** `.agents/skills/react-native-pro/SKILL.md` when creating, changing, reviewing, or shipping this app; read its relevant `references/` before making architecture or UX decisions. Use the official `expo/skills` and the installed Expo SDK documentation for version-specific guidance.

- **Project foundation:** Expo + React Native + strict TypeScript; Expo Router in `src/app`; `@/* -> ./src/*`; `src/features`, `src/shared`, `src/core`; routes are thin. Never run `npm run reset-project` against an existing project. New projects must start with `npx create-expo-app@latest` followed by `npm run reset-project`.
- **Architecture:** feature-first clean boundaries. `app` composes; features own UI/hooks/API/domain; shared/core must not depend on features; domain stays pure. Expose features through their public `index.ts`.
- **UI:** minimalist professional by default unless product brief or screenshots specify otherwise; use semantic tokens and accessible primitives. Follow provided screenshots when present. `react-native-safe-area-context`, `react-native-svg`, Lucide, and compatible stable NativeWind are standard; check NativeWind/Expo compatibility before configuring. Support light/dark/system, system default.
- **Languages:** EN (`en`), FR (`fr`), AR (`ar`). Detect device **primary** language; if unsupported, fall back to **French**. Missing keys fall back to French. Persist user override only in non-secret storage. Native Arabic RTL may need coordinated reload/restart and on-device verification; an unsupported RTL device locale must resolve to French **LTR**.
- **Data:** TanStack Query for server cache; Axios as a single transport; Zod parse at trust boundaries; Zustand for small client state; React Hook Form + Zod for forms. `expo-secure-store` for small session secrets, never AsyncStorage for credentials.
- **Security:** no sensitive `EXPO_PUBLIC_` values or embedded secrets, HTTPS, validated inputs/deep links, backend authorization, least-privilege permissions, redacted telemetry, verified auth/logout/session lifecycle, audited dependencies, controlled EAS credentials and update compatibility. Do not claim security without review.
- **UX quality:** loading/empty/error/offline states, safe areas, scalable text, screen-reader labels, keyboard-safe input, RTL, contrast and reduced motion. Test iOS and Android behavior; web when targeted.
- **Release gates:** TypeScript, lint, relevant tests, `npx expo install --check`, `npx expo-doctor`, locale/RTL/theme checks, security review, real app builds. Report commands actually run and unresolved blockers.
- **Synchronization:** whenever using this skill in the repository, refresh both root `AGENTS.md` and `CLAUDE.md` using `node .agents/skills/react-native-pro/scripts/sync-agent-instructions.mjs --root .`; keep local custom instructions outside the managed block.
